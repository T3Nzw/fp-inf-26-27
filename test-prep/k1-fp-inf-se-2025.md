## Задача 1

Да се дефинира безкраен поток от всички числа близнаци.
Две числа наричаме числа близнаци, ако са прости и разликата между тях е равна на 2.

```hs
take 5 twinPrimes → [(3,5),(5,7),(11,13),(17,19),(29,31)]
```

## Задача 02

Да се дефинира алгебричен тип данни, представящ лицата на монета (ези или тура).
Да се дефинират следните функции, използващи този АТД:

- `flipCoin :: Coin -> Coin`: Обръща лицето на монета
- `flipNCoin :: Int -> Coin -> Coin`: Обръща лицето на монета n последователни пъти
- `coinFlips :: Coin -> [Coin]`: Генерира безкрайна последователност от последователни обръщания, започвайки от даденото лице
- `minFlips :: [Coin] -> Int`: По списък с лица на монети, намира минималния брой размествания така, че всички ези да предхождат всички тура в списъка
- `coinField :: [Coin] -> Maybe (Int, Coin)`:  По списък от лица намира дължината най-дългата подредица от съседни еднакви лица, както и самото лице в тази подредица. Ако списъкът е празен, то няма такава подредица.

```hs
minFlips [Heads, Tails, Tails, Tails, Tails, Heads, Tails]  → 1
coinFlips Heads  → [Heads, Tails, Heads, Tails, …]
coinField [Tails, Heads, Tails, Tails, Heads] → Just (2, Tails)
```

## Задача 3

Да се дефинира алгебричен тип данни, представящ музикално произведение.
Всяко музикално произведение се характеризира с име, изпълнител и жанр,
описани със символни низове, както и времетраене в секунди, описано като Int.

Да се дефинира алгебричен тип данни Playlist, който представлява последователност
от музикални произведения. Да се дефинират следните функции:

- `duration :: Playlist -> Int`: Връща продължителността на плейлиста в секунди
- `shorterThan :: Int -> Playlist -> Playlist`: Връща нов плейлист от всички произведения с продължителност, по-малка от подадената
- `artists :: Playlist -> [String]`: Връща списък от уникалните имена на всички изпълнители в плейлиста без повторения
- `mostPopularGenre :: Playlist -> [String]`: Връща заглавията на всички музикални произведения, чийто жанр е най-често срещан в плейлиста. Ако има повече от един такъв жанр, да се върнат заглавията на песни от всички такива жанрове.
