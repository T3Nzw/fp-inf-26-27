## Задачa 01

Да се дефинира функция, която приема две функции и връща тяхната композиция.
Да се дефинира оператор за композиция.

```hs
ghci> add1 x = x + 1
ghci> mul3 x = x * 3

```

## Задачa 13

В Haskell можем да дефинираме свои типове данни
(т.нар. алгебрични типове данни). Например,
можем да дефинираме тип за човек по следния начин:

```hs
data Person = Person
  { name :: String
  , age :: Int
  }
```

и да създаваме стойности така

```hs
p :: Person
p = Person { name = "Alex", age = 22 }
```

и да извличаме стойностите отвътре

```hs
ghci> name p
"Alex"
ghci> age p
22
```

Да се дефинира следния набор от функции:

- `notUnderage :: [Person] -> [Person]`, която взима само пълнителните хора;
- `sortPeople :: [Person] -> [Person]`, която сортира хората по два ключа: възраст и име;
- `groupSameAge :: [Person] -> [[Person]],`, която групира хората, които са на една и съща възраст.
  Във всяка група хората са подредени в обратна лексикографска наредба.
