# Индуктивни типове данни

Дърветата са една от най-често използваните
структури от данни, така че е смислено да се запитаме
дали можем да дефинираме дървета и в Haskell.
Например, в C++ можем да дефинираме двоично дърво по следния начин:

```cpp
template<typename T>
struct Node {
  T data;
  Node *left, *right;
};
```

където лявото и дясното поддърво са указатели към същия
тип, който дефинираме. В C++ е необходимо експлицитно
да укажем, че това са указатели, а не само `Node`.
Заради позоваването на себе си за дефиницията си,
такъв тип се нарича рекурсивен или индуктивен.
По-сложни структури от данни в C++ могат да се
постигнат и чрез полиморфни йерархии.

Haskell ни дава по-лесен начин да дефинираме
такива типове, където не е необходимо да се грижим
за указатели, памет, полиморфни йерархии, правилно
клониране и т.н., чрез *алгебрични типове данни*,
като синтаксисът е същия като и за неиндуктивните такива.

Например, можем да дефинираме двоично дърво с елементи
от произволен тип по следния начин:

```hs
data BinTree a = Empty | Node a (BinTree a) (BinTree a)
```

Де факто вече сме се сблъсквали с доста по-примитивен
рекурсивен тип, а именно - списъците. Можем да си дефинираме
и собствен тип за списък:

```hs
data List a = Nil | Cons a (List a)
```
